# 세광/오딘 쇼핑몰 카테고리 구조안 (2026-09-05)

경쟁사 8곳 + 대형 플랫폼 4곳의 카테고리를 조사해 세광(오딘) 쇼핑몰(gagucafe114.com)에 맞는 카테고리 구조를 제안합니다.

- 조사 방법: 각 사이트를 직접 열지 못하는 환경(접속 차단)이라 검색엔진에 색인된 카테고리 페이지 목록으로 확인했습니다. 따라서 "확인됨"은 검색 결과에 실제 카테고리 페이지 주소가 나온 것이고, 나머지는 추론(확신도 표기)입니다.
- 사장님 종합계획설계도(카테고리 페이지)의 품목 코드 체계(T=탁자, C=의자, SF=소파, OD=아웃도어, TG=탁자다리, 소재 약어 LP/HP/sw/ws/cm 등)를 카테고리와 1:1로 맞췄습니다.

## D. 왜 이 구조인가 (근거)

- 1. 업소용 전문몰 7/8곳이 쓰는 "품목 → 소재" 구조를 기본으로 유지해 기존 손님과 검색엔진 유입이 끊기지 않습니다.
- 2. 이케아·한샘의 "공간 축"을 업소용에 맞게 "업종 축"으로 바꿔 추가하면, 창업자(카페·식당 사장)가 "우리 가게에 맞는 것"을 한 번에 봅니다. 업소용 몰 중 하이퍼스만 이 축이 있고 품목 축이 약해서, 두 축을 다 갖추면 국내에서 앞서갑니다(추론 80%).
- 3. 상판·다리·컬러칩 부품 축은 세광이 제조사이기 때문에 가능한 카테고리이고, 경쟁사 중 한국TA·금성파지오만 부분적으로 갖고 있습니다.
- 4. 카테고리 코드를 이카운트 품목코드(T/C/SF/OD + 소재 약어)와 맞추면 쇼핑몰 ↔ ERP 재고 연동(이 저장소의 MCP 서버)과 원가계산기가 같은 코드를 씁니다.

## E. 적용 순서 (권장)

1. 1단계(1주): 탁자 하위를 "나무 계열 / 인조 상판 / 세라믹·스텐·기타"로 재편, 집기 중복 정리.
2. 2단계(2주): 카페24 다중 카테고리로 업종 탭 7개 생성, 상품별 태그 부여(상품 약 500종 기준 반나절 작업, 추론 70%).
3. 3단계(1개월): 부품·컬러칩·세트·주문제작 메뉴 신설, 이카운트 품목코드와 카테고리 코드 통일.

## G. 코드·코드명 체계 (빅데이터 기초자료용) — 사장님 방식 기준 개정

사장님 원안(2026-09-05 설명): `Cst001-at-at-bk`
- `C` 대분류(대문자) · `st` 소재(소문자) · `001` 일련번호 · 1번째 대시 프레임 색 · 2번째 대시 등판 색 · 3번째 대시 방석 색
- 제약: 품목코드 20자 이내, 이카운트 입력에 문제 없을 것

### 1. 개정안 — 원안 구조는 그대로, 자릿수만 고정

```
[대분류 1][소재 2][일련 3] - [프레임색 2] - [등판색 2] - [좌판색 2] - [규격 4, 탁자류만]
 C        st      001      - at          - at         - bk                      = 15자  나비수인 엔틱 검정방석
 T        hp      031      - wt(상판)    - bk(다리)   - bk(엣지)   - 1200       = 20자  HPL 화이트 상판, 검정 다리·엣지, 가로 1200
 G        st      005      - bk(다리)    - 00         - 00         - 0720       = 20자  철재 다리 검정, 높이 720
 S        wo      008      - na          - br         - br                      = 15자  목재소파 내추럴 프레임, 브라운 가죽
```

- 앞 6자(`Cst001`)는 **모델코드**, 뒤 대시 부분은 **변형코드**(색·규격)입니다. 모델 하나에 색상 변형이 여러 개 달리는 구조라 사장님 원안과 같습니다.
- 자릿수를 고정하면 엑셀에서 `LEFT(코드,1)`=대분류, `MID(코드,2,2)`=소재, `MID(코드,4,3)`=일련번호로 바로 뽑힙니다. 대소문자가 섞여도 위치로 읽으니 이카운트가 대문자로 바꿔도 문제 없습니다.
- 최대 길이: 6 + 3×3 + 5 = 20자. 20자 제한에 딱 맞습니다. 대시 3개의 뜻은 품목마다 고정합니다: 의자·소파는 프레임/등판/좌판, 탁자는 상판/다리/엣지, 상판 단품은 상판/엣지/00, 다리 단품은 다리/00/00.
- 부위가 없으면 그 자리는 비우지 말고 `--`처럼 생략하지 말고 **`00`**을 넣습니다(예: 등판 없는 스툴 `Cst012-bk-00-bk`). 자릿수가 흔들리면 엑셀 수식이 깨집니다.
